# Stockbridge Landing

Este é um projeto React utilizando **Next.js**, **Tailwind CSS**, e diversos componentes da **Radix UI** para criar uma interface moderna e acessível.

## 🧱 Tecnologias

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Radix UI](https://www.radix-ui.com/)
- [React Hook Form](https://react-hook-form.com/)
- [Zod](https://zod.dev/)
- [Lucide React Icons](https://lucide.dev/)
- [Recharts](https://recharts.org/)
- [Typescript](https://www.typescriptlang.org/)

## 🚀 Como rodar o projeto localmente

### 1. Clone o repositório

```bash
git clone https://github.com/juravellar/stockbridge-landing.git
cd stockbridge-landing
````

### 2. Instale as dependências

Certifique-se de ter o **Node.js** (versão 18 ou superior) instalado.

```bash
npm install
# ou
yarn install
```

### 3. Inicie o servidor de desenvolvimento

```bash
npm run dev
# ou
yarn dev
```

O projeto estará disponível em `http://localhost:3000`.

## 📦 Scripts disponíveis

* `dev` — Inicia o servidor de desenvolvimento (`next dev`)
* `build` — Compila o projeto para produção (`next build`)
* `start` — Inicia o servidor com o build de produção (`next start`)
* `lint` — Executa o linter (`next lint`)

## 🛠 Requisitos

* Node.js v18+
* npm ou yarn
